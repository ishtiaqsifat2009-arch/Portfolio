High-Throughput Alpha-Beta Search Engine

Engineered around a Negamax framework with Principal Variation Search (PVS). Aggressively prunes subtrees while maintaining tactical soundness across deep combinatorial branches.

  • Quiescence Search: Evaluates captures and checks with a stand-pat cutoff to eliminate the horizon effect in volatile tactical lines.
  • Transposition Table (TT): Dual-tier depth-preferred cache with 64-bit Zobrist hashing to instantly retrieve previously calculated positions.
  • Pruning Heuristics: Late Move Reductions (LMR), Null Move Pruning (NMP), and Reverse Futility Pruning for maximum search depth per clock cycle.
🎯

Dynamic Move Ordering Pipeline

Alpha-Beta efficiency fundamentally hinges on move ordering. The search engine sorts candidate moves to maximize beta cutoffs on the very first branch explored:

1. TT Hash Move → 2. MVV-LVA Captures → 3. Killer Moves → 4. History Counter
♟️

Branchless Bitboard Architecture

Entire 64-square chessboard states are represented by 64-bit words. Sliding piece attack rays (Bishops and Rooks) use pre-calculated Magic Bitboards with BMI2 intrinsics (_pext_u64), turning complex line-of-sight checks into constant-time table lookups.
